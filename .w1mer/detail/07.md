# Task 07: Implement register-based VM (operand stack, execution loop, call frames)

## Context

Task 06 (pending) will design the opcode set and bytecode format — the compilation of AST
into bytecode instructions. Task 07 implements the **runtime execution engine** that reads
those bytecode instructions and interprets them. This is the second step in converting the
tree-walking interpreter (`src/interpreter.rs`, 4869 lines) into a bytecode VM.

The current interpreter evaluates AST nodes directly by pattern-matching on `Expr` and `Stmt`
variants. The VM replaces that AST-walking dispatch with an **instruction fetch-decode-execute
loop** that operates on a **register file** (operand stack), a **program counter**, and a **call
frame stack**.

## Value Model (from `src/value.rs`)

The VM's register file stores `Value` instances. `Value` is a Rust enum:

```rust
pub enum Value {
    Number(f64),
    String(String),
    Bool(bool),
    Null,
    Undefined,
    Object(ObjectRef),  // Rc<RefCell<Object>>
}
```

`Object` carries:
- `props: HashMap<String, Value>` — own enumerable + non-enumerable properties
- `non_enumerable_props: HashSet<String>` — shadow markers
- `proto: Option<ObjectRef>` — prototype chain link
- `internal: Internal` — Plain / Array(Vec<ArraySlot>) / Function{params,body} / Native(name) / Bound{target,bound_this,bound_args}

Key Value methods already defined:
- `is_callable()` — checks if internal is Function/Native/Bound
- `is_truthy()` — truthiness coercion
- `to_number()` — numeric coercion
- `to_string()` — string coercion (via Display impl)
- `type_name()` — returns "number"/"string"/"boolean"/"object"/"undefined"/"function"
- `abstract_eq()` — == semantics (ES SameValueZero-like)
- `to_primitive()` — ToPrimitive abstract operation

**Design principle**: The VM's register file is `Vec<Value>`. Registers hold `Value` instances.
The VM does NOT introduce a new value type — it reuses the existing `Value` enum entirely.

## Current Interpreter Architecture (from `src/interpreter.rs`)

### Env (lexical environment)
```rust
struct Env {
    values: HashMap<String, Binding>,  // name → (value, mutable)
    parent: Option<Rc<RefCell<Env>>>,   // outer environment
}
```
- `Binding { value: Value, mutable: bool }`
- `Env::get(name)` — look up in own scope, then walk parent chain
- `Env::assign(name, value)` — assign to existing binding, walk up, or define in current scope
- `Env::define(name, value, mutable)` — define a new binding in current scope

### Flow enum (control flow results)
```rust
enum Flow {
    Value(Value),    // expression returned a value
    Return(Value),   // return statement
    Throw(Value),    // throw statement
    Break,           // break statement
    Continue,        // continue statement
}
```

### Key execution patterns

1. **eval_expr(expr)** — evaluates an expression, returns `JsResult<Value>`
2. **eval_stmt(stmt)** — evaluates a statement, returns `JsResult<Flow>`
3. **eval_statements(stmts)** — evaluates a block of statements sequentially
4. **with_child(stmts)** — creates child environment, evaluates, restores parent
5. **call(callee, args, this_value, construct)** — function call with `this` binding
6. **call_native(name, args, this_value, construct)** — dispatch to built-in methods
7. **step()** — increments step counter, checks step limit
8. **enter_call() / leave_call()** — manage call depth

### Call mechanism (critical for VM call frames)

The `call()` function handles:
- **Native functions**: dispatch via `call_native()` match arm
- **Function declarations**: 
  1. `enter_call()` — increment call depth, check limit
  2. Clone current env as `previous`
  3. Look up closure env from `closures` map
  4. Create child env: `Env::child(closure_env)`
  5. Set `this` on child env
  6. Define parameters from args
  7. Evaluate function body: `eval_statements(&body)`
  8. Restore parent env: `env = previous`
  9. `leave_call()` — decrement call depth
  10. Convert Flow → Value (Return → value, Throw → Err, etc.)
- **Bound functions**: re-enter with combined args

### Exception handling (try/catch/finally)

```rust
Stmt::Try { block, catch_param, catch_block, finally_block }
```
1. Evaluate `block` in child env
2. If `Flow::Throw(v)`:
   - If `catch_block` exists: define `catch_param = v`, evaluate `catch_block` in child env
   - Otherwise propagate throw
3. If `finally_block` exists: evaluate it after catch (or after block if no catch)
4. Finally's throw/return/break/continue overrides the pending result

### 7.1 VM struct

```rust
pub struct Vm {
    // --- Operand stack (register file) ---
    // Each register holds a Value. The stack is used for:
    // - Expression evaluation (push operands, pop results)

    // --- Output ---
    output: Vec<String>,
```

### 7.2 CallFrame struct

```rust
pub struct CallFrame {
    // --- Bytecode position ---
    pc: usize,                          // return address (where to resume)
    func: Option<ObjectRef>,            // the function being called (for closures)
    
    // --- Register allocation ---
    base_register: usize,               // base of this frame's register slice
    num_registers: usize,               // total registers allocated for this frame
    
    // --- Environment ---
    saved_env: Rc<RefCell<Env>>,        // parent environment (for restoration)
    closure_env: Option<Rc<RefCell<Env>>>,  // closure environment (from outer scope)
    
    // --- Control flow state ---
    pending_flow: Option<Flow>,         // break/continue/return/throw in progress
    loop_target: Option<usize>,         // bytecode pc for break target (loop/switch)
    continue_target: Option<usize>,     // bytecode pc for continue target
    
    // --- Call depth ---
    depth: usize,                       // nesting depth of this call
}
```

### 7.3 Execution loop

```
fn run(&mut self, program: Program) -> JsResult<Value> {
    // 1. Compile AST to bytecode (produced by task 06)
    self.bytecode = compile(program);
    
    // 2. Initialize environment and builtins
    self.setup_builtins();
    
    // 3. Execute the main dispatch loop
    loop {
        // Check step limit
        self.step()?;
        
        // Fetch next instruction
        let instruction = self.fetch()?;
        
        // Decode and execute
        match instruction {
            // --- Literal instructions ---
            PushNumber(n) => self.push(Value::Number(n)),
            PushString(s) => self.push(Value::String(s)),
            PushBool(b) => self.push(Value::Bool(b)),
            PushNull => self.push(Value::Null),
            PushUndefined => self.push(Value::Undefined),
            
            // --- Variable access ---
            GetLocal(name_index) => {
                let name = self.read_string(name_index);
                let value = self.env.borrow().get(&name)
                    .ok_or_else(|| JsError::reference_error(format!("{name} is not defined")))?;
                self.push(value);
            }
            SetLocal(name_index) => {
                let name = self.read_string(name_index);
                let value = self.pop();
                self.env.borrow_mut().assign(&name, value)?;
            }
            DefineLocal(name_index, mutable) => {
                let name = self.read_string(name_index);
                let value = self.pop();
                self.env.borrow_mut().define(name, value, mutable);
            }
            
            // --- Binary operations ---
            BinaryOp(op) => {
                let right = self.pop();
                let left = self.pop();
                let result = self.eval_binary(left, op, right)?;
                self.push(result);
            }
            
            // --- Unary operations ---
            UnaryOp(op) => {
                let operand = self.pop();
                let result = self.eval_unary(op, operand)?;
                self.push(result);
            }
            
            // --- Function calls ---
            Call(func_index, arg_count, is_new) => {
                let this_value = self.pop();
                let args = (0..arg_count).map(|_| self.pop()).collect::<Vec<_>>().into_iter().rev().collect();
                let func = self.read_value(func_index);
                self.execute_call(func, args, this_value, is_new)?;
            }
            
            // --- Control flow ---
            Jump(target) => self.pc = target,
            JumpIfFalse(target) => {
                let value = self.pop();
                if !value.is_truthy() {
                    self.pc = target;
                }
            }
            JumpIfTrue(target) => {
                let value = self.pop();
                if value.is_truthy() {
                    self.pc = target;
                }
            }
            Loop(start) => { self.pc = start; }
            
            // --- Return ---
            Return => {
                let value = self.pop();
                return Ok(value);
            }
            
            // --- Throw ---
            Throw => {
                let value = self.pop();
                return Err(JsError::runtime(value.to_string()));
            }
            
            // --- Break/Continue ---
            Break => {
                let frame = self.top_frame();
                self.pc = frame.loop_target.unwrap_or_else(|| {
                    // break outside loop is a syntax error
                    panic!("break used outside loop");
                });
            }
            Continue => {
                let frame = self.top_frame();
                self.pc = frame.continue_target.unwrap_or_else(|| {
                    panic!("continue used outside loop");
                });
            }
            
            // --- Try/Catch/Finally ---
            Try { block_end, catch_handler, finally_handler } => {
                // Evaluate block, if throw jump to catch_handler, always run finally
            }
            
            // --- etc. ---
        }
    }
}
```

### 7.4 Call frame management

```rust
fn execute_call(&mut self, func: Value, args: Vec<Value>, this_value: Value, construct: bool) -> JsResult<()> {
    // Validate func is callable
    if !func.is_callable() {
        return Err(JsError::type_error(format!("{} is not a function", func.type_name())));
    }
    
    let func_obj = match func {
        Value::Object(o) => o,
        _ => unreachable!(),
    };
    
    let internal = func_obj.borrow().internal.clone();
    
    match internal {
        Internal::Native(name) => {
            // Built-in: dispatch via call_native
            let result = self.call_native(&name, &args, &this_value, construct);
            self.push(result);
        }
        Internal::Function { ref params, ref body } => {
            // User-defined function: push call frame
            self.enter_call(func_obj, params.clone(), body.clone(), args, this_value, construct)?;
        }
        Internal::Bound { target, bound_this, bound_args } => {
            // Re-entrant bound call
            let mut combined = bound_args.clone();
            combined.extend(args);
            self.execute_call(Value::Object(target), combined, bound_this, construct)?;
        }
        _ => {
            return Err(JsError::type_error("object is not a function"));
        }
    }
    Ok(())
}

fn enter_call(&mut self, func: ObjectRef, params: Vec<String>, body: Vec<Stmt>,
              args: Vec<Value>, this_value: Value, construct: bool) -> JsResult<()> {
    // Check call depth
    self.check_call_depth()?;
    
    // Save current state as call frame
    let current_env = self.env.clone();
    let current_pc = self.pc;
    let current_flow = self.pending_flow.take();
    
    // Look up closure environment
    let func_ptr = Rc::as_ptr(&func) as usize;
    let closure_env = self.closures.get(&func_ptr)
        .cloned()
        .unwrap_or_else(|| current_env.clone());
    
    // Create child environment
    let child_env = Env::child(closure_env);
    
    // Set up call frame
    let frame = CallFrame {
        pc: current_pc,
        func: Some(func),
        base_register: self.registers.len(),
        num_registers: 0,
        saved_env: current_env,
        closure_env: Some(closure_env),
        pending_flow: current_flow,
        loop_target: None,
        continue_target: None,
        depth: self.call_depth(),
    };
    
    // Push frame onto stack
    self.call_stack.push(frame);
    
    // Set new environment
    self.env = child_env;
    
    // Define 'this'
    let this_obj = if construct {
        // Create new plain object with function's prototype
        let proto = func.borrow().props.get("prototype")
            .cloned()
            .unwrap_or(Value::Object(self.object_proto.clone()));
        let obj = Object::plain();
        obj.borrow_mut().proto = match proto {
            Value::Object(p) => Some(p),
            _ => Some(self.object_proto.clone()),
        };
        Value::Object(obj)
    } else {
        this_value
    };
    self.env.borrow_mut().define("this".to_string(), this_obj, true);
    
    // Define parameters
    for (i, name) in params.iter().enumerate() {
        let value = args.get(i).cloned().unwrap_or(Value::Undefined);
        self.env.borrow_mut().define(name.clone(), value, true);
    }
    
    // Evaluate body
    let result = self.eval_statements(&body)?;
    
    // Restore environment
    self.env = self.call_stack.pop().unwrap().saved_env;
    
    // Convert result to value
    match result {
        Flow::Value(v) | Flow::Return(v) => self.push(v),
        Flow::Throw(v) => return Err(JsError::runtime(v.to_string())),
        Flow::Break => return Err(JsError::syntax_error("break used outside loop")),
        Flow::Continue => return Err(JsError::syntax_error("continue used outside loop")),
    }
    
    Ok(())
}
```

### 7.5 Environment management in VM

The VM reuses the existing `Env` struct from `src/interpreter.rs`. The key difference is:

**Current interpreter**: `env` is a field on `Interpreter`, cloned/restored manually in `with_child()`.

**VM**: `env` is a field on `Vm`, and each `CallFrame` carries a `saved_env`. When entering a call,
the current env is saved into the frame. When returning, the saved env is restored.

This is semantically identical to the current interpreter's `with_child()` pattern:
```rust
fn with_child(&mut self, statements: &[Stmt]) -> JsResult<Flow> {
    let previous = self.env.clone();
    self.env = Env::child(previous.clone());
    let result = self.eval_statements(statements);
    self.env = previous;
    result
}
```

The VM makes this explicit in the call frame rather than implicit in the call stack.

### 7.6 Exception handling in VM

```rust
// Pseudocode for Try/Catch/Finally execution
fn execute_try(&mut self, block_end: usize, catch_handler: Option<usize>,
               catch_param: Option<String>, catch_block_end: usize,
               finally_handler: Option<usize>) -> JsResult<()> {
    // Save exception handler state
    let previous_handler = self.exception_handler.take();
    self.exception_handler = Some(ExceptionHandler {
        catch_handler,
        catch_param,
        catch_block_end,
        finally_handler,
        saved_pc: self.pc,
    });
    
    // Execute try block
    let result = self.eval_statements_in_range(0..block_end)?;
    
    // Clear handler
    self.exception_handler = previous_handler;
    
    // Handle result
    match result {
        Flow::Value(v) | Flow::Return(v) | Flow::Break | Flow::Continue => {
            // If finally exists, run it
            if let Some(finally_h) = finally_handler {
                self.execute_finally(finally_h)?;
            }
            Ok(())
        }
        Flow::Throw(v) => {
            if let Some(ch) = catch_handler {
                // Jump to catch handler
                self.pc = ch;
                if let Some(param) = &catch_param {
                    self.env.borrow_mut().define(param.clone(), v, true);
                }
                // Execute catch block
                let catch_result = self.eval_statements_in_range(ch..catch_block_end)?;
                // Run finally
                if let Some(finally_h) = finally_handler {
                    self.execute_finally(finally_h)?;
                }
                Ok(())
            } else {
                // Propagate throw
                Err(JsError::runtime(v.to_string()))
            }
        }
    }
}

fn execute_finally(&mut self, finally_handler: usize) -> JsResult<()> {
    let saved_pc = self.pc;
    self.pc = finally_handler;
    let result = self.run_until_return_or_throw()?;
    self.pc = saved_pc;
    result
}
```

## Opcode Set Design (assumes task 06 produces these)

The instruction set mirrors the current interpreter's dispatch arms. Each `Stmt` and `Expr` variant
maps to one or more bytecode instructions:

| AST Node | Bytecode Instructions |
|----------|----------------------|
| `Stmt::VarDecl` | `DefineLocal(name_idx, mutable)` |
| `Stmt::VarDecls` | Multiple `DefineLocal` |
| `Stmt::FunctionDecl` | `DefineLocal(name, false)` + compile body |
| `Stmt::Return` | `Return` (with value on stack) |
| `Stmt::Throw` | `Throw` (with value on stack) |
| `Stmt::Try` | `Try{block_end, catch_handler, finally_handler}` |
| `Stmt::If` | `JumpIfFalse(target)` + then/else branches |
| `Stmt::While` | `Loop(start)` + condition + `JumpIfFalse(exit)` |
| `Stmt::For` | Init + `Loop(start)` + condition + body + update |
| `Stmt::ForIn` | Evaluate RHS → enumerate keys → loop |
| `Stmt::Switch` | Discriminant + case comparisons + jumps |
| `Stmt::Break` | `Break` |
| `Stmt::Continue` | `Continue` |
| `Stmt::Block` | Sequential execution |
| `Stmt::Expr` | Evaluate expression (discarded) |
| `Expr::Number` | `PushNumber(n)` |
| `Expr::String` | `PushString(s)` |
| `Expr::Bool` | `PushBool(b)` |
| `Expr::Null` | `PushNull` |
| `Expr::Undefined` | `PushUndefined` |
| `Expr::Identifier` | `GetLocal(name_idx)` |
| `Expr::This` | `GetThis` |
| `Expr::Member` | `GetMember(object, property)` |
| `Expr::Index` | `GetIndex(object, index)` |
| `Expr::Call` | Evaluate callee + args → `Call(func, arg_count, false)` |

## Risk List

| Risk | Severity | Mitigation |
|------|----------|------------|
| **Register file grows unbounded** — Each expression evaluation pushes to the stack. Deeply nested expressions could exhaust memory. | High | Pre-compute register allocation during compilation. Limit stack depth. Use a fixed-size register file with overflow to heap. |
| **Call frame stack overflow** — Recursive calls create frames. Default call depth is 16 in RuntimeLimits. | Medium | Enforce `max_call_depth` in `enter_call()`. Same as current interpreter. |
| **Step limit enforcement** — The VM loop must check step count every iteration. | Low | Simple counter increment + check in the main loop. |
| **Environment cloning overhead** — `Env::child()` clones the parent env. In a tree-walking interpreter this is fine; in a VM with many calls, this could be slow. | Medium | Consider using `Rc<RefCell<Env>>` for env references (already used). The VM should not clone envs, only reference-count them. |

## Implementation Notes

1. **Instruction enum**: Define `Instruction` as a Rust enum with variants for each opcode. Use `std::mem::discriminant` for matching (same pattern as `TokenKind`).

2. **String/number pool**: Store literal strings and numbers in separate `Vec<String>` and `Vec<f64>` pools. Instructions reference by index.

3. **Register allocation**: For simple expressions, use the operand stack (push/pop). For complex expressions (function bodies), allocate a fixed register slice per call frame.

4. **Error handling**: The VM returns `JsResult<Value>` (same as `Interpreter::run()`). Errors propagate through the call stack via `Err(JsError::...)`.

5. **No unsafe code**: The VM should use safe Rust only. `Rc<RefCell<T>>` for shared ownership, `Vec` for stacks.

6. **Testing**: Add tests to `src/vm.rs` and extend `tests/` directory with VM-specific tests.

7. **Performance baseline**: Run the existing microbenchmarks (`tests/benchmarks.rs`) with and without `--vm` to measure improvement.
